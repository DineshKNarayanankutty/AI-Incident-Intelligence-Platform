# AI-300 Domain Mapping

| AI-300 domain | Project implementation |
|---|---|
| Designing and implementing MLOps infrastructure | `infra/bicep`, Azure ML workspace, ACR, Key Vault, App Insights |
| Implementing ML model lifecycle and operations | `azure_ml/data`, `azure_ml/components`, `azure_ml/pipeline.yml`, model registration, managed endpoint |
| Designing and implementing GenAIOps infrastructure | `genai/prompts`, Foundry client, evaluation dataset, CI workflow |
| Implementing GenAI quality assurance and observability | evaluation runner, V1/V2 comparison, OpenTelemetry/Azure Monitor, metrics |
| Optimizing GenAI systems and model performance | prompt optimization comparison, severity/model metrics, drift-triggered retraining |

The repository deliberately demonstrates the lifecycle rather than only a model-training notebook.
